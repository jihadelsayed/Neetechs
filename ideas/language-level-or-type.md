# Idea 001 — Language Level / Type

**Date captured:** 2026-11-10  
**Status:** Future idea — do not implement yet  
**Working name:** Language Level / Type (alternative: Communication Style / Register)

## Core concept
Allow users to select the **kind or level of language** appropriate for their audience or context. This is **not** a choice between human languages such as Arabic or English. The same human language can be expressed in different registers or styles.

## Examples from the original idea
- **Computer science language:** technical terminology and explanations suitable for software and computer science.
- **Author / writer language:** writing-oriented, literary, or narrative phrasing.
- **Kids' language:** simple vocabulary and explanations suitable for children.
- **Other types:** to be defined later.

## Open design questions (for later)
- Is this a setting for explanations, AI-generated text, or an entire Neetechs product?
- Should users choose a **domain/type** (e.g., computer science) separately from a **level/audience** (e.g., beginner, child, expert)?
- Should the selection persist per user, project, or conversation?

## Scope
Capture the idea only. No UX, model, API, or database work is authorized by this note.
